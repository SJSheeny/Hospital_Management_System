# Hospital Management System

## Project Overview

The Hospital Management System is a console-based C++ application designed to manage patient admissions, emergency cases, patient searches and discharges. It uses different data structures and algorithms to organize patient records and demonstrate their practical applications in hospital management.

## Features

* **Patient Admission:** Admit patients into the system.
* **Emergency Admission:** Give emergency patients priority in the queue.
* **Patient Discharge:** Discharge patients from the queue or by patient ID.
* **Patient Search:** Search for patients using their unique IDs.
* **Undo and Redo:** Manage previous operations using stacks.
* **Patient Queue Display:** View patients waiting in the queue.
* **Discharge Archive:** Store and display discharged patient records.
* **Patient Sorting:** Sort patients by severity, department and patient ID.
* **Performance Analysis:** Compare the performance of different data structures and algorithms.

## Data Structures and Algorithms

This project demonstrates the following concepts:

* **Queue:** Manages patient admissions and discharge order.
* **Linked List:** Implements the patient queue, stack and discharge archive.
* **Stack:** Supports undo and redo operations.
* **Binary Search Tree (BST):** Organizes patient records by ID for searching.
* **Merge Sort:** Sorts patients by severity, department and ID.
* **Performance Analysis:** Measures execution time for BST insertion, different search methods and merge sort.

## How to Compile and Run

### Requirements

* A C++ compiler such as GCC or MinGW
* A terminal or command prompt

### Compilation

Save the source code as `hospital_management.cpp` and run:

```bash
g++ hospital_management.cpp -o hospital_management
```

### Run the Program

**Windows:**

```bash
hospital_management.exe
```

**Linux/macOS:**

```bash
./hospital_management
```

## How to Use

Run the program and select an option from the main menu to admit patients, manage emergency cases, discharge patients, search records, undo or redo operations, display the queue and archive, sort patients or run performance analysis.
